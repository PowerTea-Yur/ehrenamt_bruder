# Volunteer Portal

A portfolio-quality web application to connect volunteers with organizations and individuals who need help.

## Vision

Build a clean, maintainable platform where anyone can create volunteer opportunities and interested users can discover and apply for them — while learning professional C# and ASP.NET development.

## Goals

- Learn modern C# and ASP.NET Core
- Build a portfolio-quality application
- Follow professional software engineering practices
- 3-tier architecture, incremental delivery
